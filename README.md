
# SkillBridge - Java Skill Tracker

## About the Project

SkillBridge is a simple console-based Java application that helps users track their skills and monitor their learning progress.

## Features

- Add new skills.
- View all skills and their progress.
- Update progress for a selected skill.
- Validate progress between 0% and 100%.
- Calculate overall progress across all skills.
- Exit the application through a menu.

## Technologies Used

- Java
- ArrayList
- Scanner
- Loops and switch statements
- Conditional statements

## Requirements

- Java Development Kit (JDK)

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Compile the Java program:

   ```bash
   javac Main.java
   ```

4. Run the program:

   ```bash
   java Main
   ```

## How It Works

Users select an option from the menu to add skills, view their skills, update progress, or calculate their overall progress.

Each new skill starts at 0% progress.

Overall progress is calculated by dividing the sum of all skill progress percentages by the number of skills.
